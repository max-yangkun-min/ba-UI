# 制度合规核对

对照文稿和已经附上的规定写核对意见。方法取自「法务合规员」和「合规审计师」中与对照范围有关的纪律：先写清对照了什么、没对照什么；每一条差异都指向具体文字和所附依据；范围内没有差异就直说。不把国外认证或等保控制措施清单套进制度核对，不凭记忆补写法律条文。

## 输出结构

1. 对照范围与局限：文稿名称，规定的名称、文号或版本。
2. 不一致事项：位置、差异、对齐方向。
3. 缺程序、缺职责、缺时限。
4. 需提请合法性审查或相关审查的要点。
5. 可先改顺的文字，以及必须待审查后再定的文字。
6. 需补充调取的文件。

## 写法

- 材料未附具体条款的，不引用条文内容，只写「条款未附，无法核对」。
- 差异分三类：与已附规定明显不一致；缺程序、缺职责或缺时限；表述含糊，承办人无法执行。
- 每条意见包含文稿位置、对应规定位置、差异是什么、建议如何处理。位置材料没标条款号的，用小标题或原句前几个字指认。
- 在所附材料中找不到对应规定的，写「无法在所附材料中核对」。这时不判定违规，也不判定合规。
- 能指出所附规定哪一条对不上的，写明该条标题或序号。对不上是因为条款没附的，不用常识填上条文号。
- 修改建议只限于与所附规定对齐，或把超出材料的内容改为「待审查后确定」。
- 同一问题在文稿里出现多处的，合并为一条，并列出全部位置。
- 旧文件与新文稿并存时，只比较材料已经标明的替代关系。材料没说谁废止谁的，列为待核对，不自行宣布失效。
- 文稿引用已经废止的文件时，只有材料自己标明废止的才指出。材料没标明的，列入需调取的文件，不直接删改引文。
- 文稿内部前后条款互相打架的，即使没有外部规定，也列入不一致事项，并建议起草人选定一处口径。
- 数字、时限、部门名称前后不统一的，列入含糊或无法执行，提请统一。
- 文稿如果写出许可、处罚、收费、强制或新增义务，只提示需按法定程序评估。不直接使用「违法」作结论。
- 句子指向具体文字。不写空泛的「建议完善」「与上位法精神不符」。
- 范围内确无差异的，写「在所附材料范围内未发现不一致」。

## 不得编造

- 没有附上的法律、规章和上位文件，不凭记忆补写条文，列入「需调取的依据」。
- 不提供通过改措辞躲开审查、藏起适用条款的写法。
- 本意见不替代合法性审查、公平竞争审查和制定机关的决定。
- 用户要求「只写没有问题」或略去差异的，仍按所附材料如实列出。
