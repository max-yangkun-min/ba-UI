# 智能体与技能同步说明

日期：2026-10-22。这份说明跟离线包放在一起。数据来自实验室这台已经在跑的 Blade，导出时没有把访问票打进包。

现场导入技能时使用的票，由现场人员自己填写。不要把实验室的 `EMBED_TOKEN`、`blade_token` 或 `proxy.env` 拷过去。

## 1. 技能：已导出，可以导入

8020 的 `GET /api/skill-store/catalog` 和 8010 的 `GET /api/skills` 都返回 40 条，条目一致。每一条都从 8010 的 `GET /api/skills/{org}/{name}/download` 下到了 zip，校验过里面有 `SKILL.md`，没有占位包，也没有令牌样式的内容。

包内位置：

```text
sync/manifest.json          技能 id、展示名、zip 路径
sync/skills/*.zip           可再次上传的技能包
sync/import-skills.py       现场导入脚本
sync/data/skill-catalog-8020.json
sync/data/skill-catalog-8010.json
```

商店里包含这些真实技能（完整 40 条以 `manifest.json` 为准），其中有 PPT 相关的两项：

| id | 展示名 |
| --- | --- |
| `BladeAI/ppt-sheng-cheng-yu-bian-ji` | PPT生成与编辑 |
| `superadmin/pptx` | 演示文稿 |
| `BladeAI/word-sheng-cheng-yu-bian-ji` | Word生成与编辑 |
| `superadmin/docx` | Word 文档 |

组织有两个：`BladeAI`（18 条）、`superadmin`（22 条）。

在生产机、Hub 已经运行之后，用现场有建库权限的用户票导入。票只放在这一次命令的环境变量里：

```bash
cd 20261022-blade-arm-offline
SKILL_IMPORT_TOKEN='现场用户票' python3 sync/import-skills.py
```

Hub 不在本机 8010 时：

```bash
SKILL_IMPORT_URL='http://127.0.0.1:8010' SKILL_IMPORT_TOKEN='现场用户票' python3 sync/import-skills.py
```

脚本对 `manifest.json` 里的每个 zip 调用 `POST /api/skills`，表单字段是 `display_name`、`org` 和 `file`。`201` 表示新建成功，`409` 表示该组织下已经有同名技能。`403` 表示这张票不能在 `BladeAI` 或 `superadmin` 下建库；预置组织会拒绝普通用户。这时改用现场管理员票再执行一次，不要改 zip，也不要把实验室的票填进来。

脚本只打印状态码和技能 id，不打印票，也不写回文件。

## 2. 智能体：只导出了目录，不能在现场导入

市场上架智能体以接口为准，共 3 条，状态都是 `published`。8020 的 `GET /api/market-publish/listings` 和 blade-os 的 `GET /api/v1/market/listings` 是同一批：

| 名称 | 分类 | 市场 id |
| --- | --- | --- |
| 合同审查智能体 | 智能体应用 | `332120ad-a354-4c76-8c9a-b9f187abf524` |
| 文摘 · 文档摘要助手 | 办公效率 | `7de3a045-c99d-4093-9d0b-30a625df6715` |
| 文巡公文校对台 | 办公效率 | `69228973-0bcd-455c-b45d-0484f0a2be3a` |

快照在：

```text
sync/data/market-listings-8020.json
sync/data/market-listings-bos.json
sync/data/published-apps.json
```

这不是安装包。市场上架必须指向目标环境里已经上线的 `service_id`。这三条的服务只存在于实验室的 blade-os。已发布应用也只有 3 个在跑：文章摘要应用、文巡公文校对台、合同审查智能体，访问地址都在实验室虚拟机上。没有会话包、镜像或数据库转储可以在现场把它们重建出来。

所以这次没有把智能体同步成可运行的应用。现场要出现同样的智能体，需要在现场的 Blade 里重新部署并再次上架。不要把快照里的实验室地址写进生产页面。

嵌入页的智能体主页只显示上面这种已上架条目：分类在左侧，常用排行在分类下面。
