# 给客户的接入说明（免登录直连工作台 / 能力中心）

> 插件版本：blade-iframe-plugin **1.1.7** ｜ 适用：已部署的 Blade Agent（`:8020`）与
> Blade Hub 能力中心（`:8010`）
> 结论：**客户侧不需要改代码、不需要登录、不需要传 token 到地址栏**。
> 工作台（`:8020`）与能力中心（`:8010`）同一条链接形式，端口不同即可。

---

## 1. 客户要做什么

只需在页面上挂一条链接（按钮或菜单项）。工作台与能力中心用同一种链接，只是端口不同：

```html
<a href="http://192.168.171.128:8020/autologin.html?token=xxx" target="_blank">
  进入智能体工作台
</a>

<a href="http://192.168.171.128:8010/autologin.html?token=xxx&next=/skills" target="_blank">
  进入能力中心
</a>
```

或者直接嵌入：

```html
<iframe src="http://192.168.171.128:8020/autologin.html?token=xxx"
        style="width:100%;height:100vh;border:0"></iframe>
```

就这一步。**其余全部由我方插件的 `autologin.html` 完成。**

---

## 2. 参数说明

| 参数 | 必填 | 说明 |
|---|---|---|
| `token` | 是（与 `refresh_token` 至少一项） | BO Access Token（JWT）。本环境已调为 **10000 小时（约 416 天）** |
| `refresh_token` | 可选 | 刷新令牌，同为本环境 **10000 小时**；带上它可支持前端续期 |
| `next` | 否 | 进入后跳转路径，默认：工作台 `/chat`、能力中心 `/`。能力中心建议 `&next=/skills` |

> ⚠️ **`token` 必须是 JWT**（`eyJ...` 开头）。`sk-blade-v3-...` 这类 **API Key**
> 虽然也能通过 `/api` 鉴权，但 `/api/auth/me` 不会返回 JWT，socket.io 实时通道
> 连不上（界面能开、对话不通）。**别把 API Key 拼进链接。**

---

## 3. 用户点下去之后发生什么

1. 浏览器打开 `autologin.html`
2. 页面把 token / refresh_token 种成同源 Cookie（`blade_token` / `blade_refresh_token`）
3. **地址栏里的 token 被 `replaceState` 抹掉**，URL 变成干净的 `.../autologin.html`
4. 页面探一次 `/api/auth/me` 确认会话真的生效
5. 成功 → 自动跳到 `/chat`，直接在工作台里

全程**不出现登录页、不出现品牌登录框**。
能力中心同理：`next=/skills` 时第 5 步跳到 `/skills`，直接进能力中心。

---

## 4. 为什么这样能免登录（技术根据，已实测）

| 事项 | 实测结果 |
|---|---|
| 登录态载体 | Cookie `blade_token`（值放 JWT 或 `sk-blade-` 都认） |
| Cookie 是否跨端口共享 | **是**。按主机共享，`:8020`（BA）与 `:8010`（BH）都认 |
| BA / BH 是否允许被 iframe 嵌入 | **是**。响应头无 `X-Frame-Options`、无 CSP |
| 跳转后是否出现登录页 | **否**。实测 `loginForm: false`，socket `connected` |
| 令牌无效时 | 停在当前页给出明确提示，**不会反复跳转** |
| 令牌有效期 | **10000 小时（约 416 天）**，实签 `exp - iat = 10000h` |

---

## 5. 令牌有效期

本环境已把 `blade-os` 应用级有效期调整为 **10000 小时（约 416 天）**，
所以一条链接可以长期使用，**不需要定期更换**。

| 项 | 值 |
|---|---|
| Access Token 有效期 | 10000 小时（约 416 天） |
| Refresh Token 有效期 | 10000 小时（约 416 天） |
| 链接实际可用时长 | **约 400 天**（受浏览器 Cookie 上限约束，见下） |
| 链接更换频率 | 基本不需要；如需轮换，重新签发一条替换即可 |

> **为什么是 400 天而不是 416 天**：Chrome 104+ 起，浏览器会把 `max-age`
> 超过 400 天的 Cookie 一律截断为 400 天。`autologin.html` 按 token 的 `exp`
> 推算 Cookie 寿命并自动钳制到这个上限，因此**会话实际寿命约 400 天**，
> 比 token 自身有效期早约 16 天。到期后重新打开一条新链接即可。

> 调整方式（部署方操作）：`PUT /api/v1/apps/<blade-os 的 id>`，
> 字段名为 **`token_expiry` / `refresh_expiry`**（注意不是 `_hours` 后缀，
> 该接口对未知字段返回 200 但会静默忽略，改完必须回读确认）。

## 6. 使用边界

本方案面向**内网受控环境**，按此前提设计与验证：

- 这条链接**等价于一把钥匙**，谁拿到链接谁就能进。请通过可信渠道分发。
- token 虽会被地址栏抹掉，但**仍会经过网关/代理日志**。
- Cookie 用 `SameSite=Lax`，不设 `HttpOnly`（`autologin.html` 是纯静态页，
  没有服务端参与），因此不防 XSS。
- 以上取舍在内网环境可接受；若要对外发布，需改用一次性票据 + 服务端种 Cookie。

> **v1.1.4 的一个已知缺陷（v1.1.6 已修）**：旧版把 HTTP **403** 也当成"token 失效"
> 并停止注入。BA 的 `/api/users/me/profile` 本来就会返回 403，于是用 `?token=` 直链
> 打开工作台时会看到侧边栏「我的分组 / **分组加载失败** / 重试」。
> 这不是 token 的问题，用 v1.1.6 重装即可。

> **另一类报错（与插件无关，但要提前知道）**：新建会话时提示
> 「用户文件目录尚未就绪，请稍后重试；已配置 Blade OS，不会降级到本地 UUID 目录」。
> 这是该用户在 Blade OS 侧漏建号。**直链会绕开门户，所以不会自愈**，需要按 sub 补投
> 一次授号事件。判定与补投步骤见 `使用手册.md` 第 8 节排障表，或
> `03_blade-service-deployer/readme-for-dev.md` 的「用户漏投 webhook」一节。

## 7. 怎么拿 token

打开一个已登录的 BA 页面，F12 控制台执行：

```js
fetch('/api/auth/me').then(r => r.json()).then(d => console.log(d.token))
```

输出的就是 JWT（本环境有效期约 416 天）。

或走 OAuth 授权码流程脚本化获取：

```bash
# 1) 浏览器打开授权地址，登录后从地址栏复制 code
#    http://<SERVER>:19000/oauth/authorize?client_id=blade-os
#      &redirect_uri=http%3A%2F%2F<SERVER>%3A8020%2Foauth%2Fcasdoor%2Fcallback
#      &response_type=code&scope=openid+profile+email&state=x

# 2) code 换 token
curl -sS -X POST http://<SERVER>:19000/oauth/token \
  -d grant_type=authorization_code -d code=<CODE> \
  -d client_id=blade-os -d client_secret=bos-oidc-5d1b8a3c \
  -d redirect_uri=http://<SERVER>:8020/oauth/casdoor/callback
```

返回体里的 `access_token` 就是要拼进链接的值。

## 8. 运维

```bash
sh /opt/blade-iframe-plugin/status.sh     # 自检，应看到 autologin page: present
sh /opt/blade-iframe-plugin/install.sh    # 容器重建 / 产品升级后重装
sh /opt/blade-iframe-plugin/uninstall.sh  # 卸载（会一并删掉 autologin.html）
```

**产品升级或 `docker compose up` 重建容器后必须重装**，否则 `autologin.html` 会丢。
